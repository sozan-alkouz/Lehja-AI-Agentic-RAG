# Lehja-AI-Agentic-RAG

An agentic Retrieval-Augmented Generation (RAG) platform for teaching Levantine Arabic to non-native speakers.

## Project Overview

This project presents a web-based learning platform that supports learning Levantine Arabic using Retrieval-Augmented Generation (RAG).

The system uses:
- n8n for workflow orchestration
- BGE-M3 for embeddings
- ChromaDB as the vector database
- GPT-5 mini as the language model
- A decision agent for selecting the next learning action

The platform includes:
- Placement Test
- Learning Mode
- Interactive Question Mode
- Pre-test and Post-test assessment
- Micro-level quizzes
